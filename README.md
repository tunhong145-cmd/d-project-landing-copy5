## 設定與資料

- 沿用既有後台與 LINE 設定；FB 像素依固定倉庫編號 `copy5` 和版本獨立配置，初始七版全部為空。
- C、E、F、G、I、J 依原版本寫入 D 項目訂單；K 沿用 X 貸款 K 版獨立提交流程。G 沿用主倉庫 G 頁面及 F／G 共用 LINE。
- 在後台「複製倉庫5 · tunhong145-cmd.github.io/d-project-landing-copy5」管理各版本 FB 像素，每版最多5個。清空或讀取失敗時不回退共用像素。

綁定新域名後，請告知管理員更新後台顯示標註；固定像素倉庫編號不變。
- LINE、訂單歸類與甲方編號不受此 FB 配置隔離影響；同一像素 ID 若跨站重複配置，事件仍會匯入同一像素。

## 部署

GitHub Pages 使用 `main` 分支的根目錄。綁定新域名時，請到此倉庫的 Settings → Pages → Custom domain 設定，並在域名服務商設定 DNS。不要綁定其他投放網站正在使用的域名。
